# Integration and trademark gate

Leave must not enter public distribution or hosted operation until Cognition
provides written approval that covers:

- wrapping `devin acp` for same-user and team remote access;
- invoking, but not redistributing, the official Devin CLI;
- supported session, rules, skills, plugin, hook, and MCP operations;
- the product name and any use of "compatible with Devin";
- the non-affiliation notice and trademark presentation.

Every user must install and authenticate the official CLI locally. Leave will
not bundle Devin binaries, read Cognition tokens, resell accounts, scrape
private stores, or claim unsupported Desktop parity.

This file records a release condition, not legal advice. Counsel must review
the written permission and the planned hosted service before the gate changes.
